# ⏳ Study Timer

## 📌 Overview
Study Timer is a minimalist, aesthetically designed web app for tracking focused study and work sessions. Styled like a soft-glass digital clock widget set against a tropical, plumeria-themed background, it combines a classic countdown timer with a stopwatch mode and daily study-time tracking to help users stay motivated and consistent.

## ✨ Features
* Toggle between **Timer** and **Stopwatch** modes
* Manual Hour / Minute / Second adjustment with `+1` and `-1` controls
* Large, easy-to-read digital display (HH:MM:SS)
* Live date and time display (e.g. `27/08/2026 10:19 AM`)
* **"Today's Total Study"** tracker that accumulates daily focused time
* Start and Reset controls for full session management
* Soft neumorphic / glassmorphic UI design with rounded card layout
* Decorative floral (plumeria) background elements for a calming aesthetic
* Fully responsive, clean, distraction-free interface
* Deployed and hosted via Netlify

## 🛠 Tech Stack
**Frontend:** Next.Js, Tailwind Css
**Hosting/Deployment:** Netlify

## ⚙️ How It Works
The app displays a digital-clock-style panel showing the current countdown or elapsed time, along with the live date/time and today's cumulative study duration. Users can:
1. Switch between **Timer** (countdown) and **Stopwatch** (count-up) modes
2. Adjust hours, minutes, and seconds using the `+1` / `-1` buttons
3. Press **Start** to begin the session and **Reset** to clear it
4. Track total daily study time automatically as sessions complete

### Core Components
* Digital Display Panel (time, date, mode label)
* Mode Switcher (Timer / Stopwatch)
* Time Adjustment Controls (Hour, Min, Sec)
* Session Controls (Start, Reset)
* Daily Study Tracker
* Decorative Background Layer
